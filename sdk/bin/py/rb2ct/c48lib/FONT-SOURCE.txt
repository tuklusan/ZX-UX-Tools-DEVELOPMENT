Changes to the glyph data: 96 printable characters, codes 32-127,
were extracted as eight bytes per glyph and stored in c48lib-font.asm.
The font is linked separately into each C48 program. Other glyph data
belong to each game's BASIC listing and are not part of the VGA font.
The license notice and source credit apply to the font in compiled tapes.
