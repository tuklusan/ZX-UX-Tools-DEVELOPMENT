# ZX-UX technical references

ZX-UX uses published ZX Spectrum and Z80 reference material. This folder
links to the original sources. It does not include copies of external
reference pages or manuals.

## Reference links

- [48K Spectrum ROM disassembly](https://skoolkit.ca/disassemblies/rom/),
  2026-04-09 edition, by Richard Dymond and contributors.
- [Spectrum ROM disassembly sources](https://github.com/ZXSpectrumVault/rom-disassemblies),
  including 48K and 128K reference material.
- [48K technical information](https://worldofspectrum.org/faq/reference/48kreference.htm)
  at World of Spectrum.
- [128K technical information](https://worldofspectrum.org/faq/reference/128kreference.htm)
  at World of Spectrum.
- [Z80 CPU User Manual](https://www.zilog.com/docs/z80/um0080.pdf)
  from Zilog.

## Private reference checkpoint

The owner retains a separate, checked private reference archive. It has 952
source files: 940 from the SkoolKit reference collection, eight in the ROM
source group, three in the World of Spectrum group, and one chess source.
The Zilog PDF is not part of that archive.

Private checkpoint archive

The private archive is **not approved for public redistribution**. Each
external source keeps its own copyright and license. A source being available
online does not by itself grant permission to copy it into ZX-UX. Do not
publish the reference archive until the relevant rights have been checked.
