# Advent — MCODER III compatibility

**Incompatible as supplied.** The unchanged publisher TZX failed during compilation: Sinclair ROM `3 Subscript wrong, 900:1` at original `900 RESTORE os: READ oc: DIM o(oc)`; one compiler tape block remained. The variable-sized `DIM` is a documented unsupported MCODER III feature (static dimensions are required). No genuine compiled TZX was produced. Original interpreted BASIC has a separate recorded human walkthrough; no source changes are permitted for this compatibility result.
