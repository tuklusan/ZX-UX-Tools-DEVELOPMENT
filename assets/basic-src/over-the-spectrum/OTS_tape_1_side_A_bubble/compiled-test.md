# Bubble — MCODER III compatibility

**Incompatible as supplied.** The original publisher TZX stopped during compilation with `3 Subscript wrong, 150:1` at `150 DIM p(n)`; one compiler tape block remained. Dynamic `DIM` is unsupported by MCODER III, which requires static dimensions. No genuine compiled TZX from the unchanged source exists. Original interpreted BASIC's 15-value sort and its real-keyboard screenshots remain documented in `walkthrough.md`.
