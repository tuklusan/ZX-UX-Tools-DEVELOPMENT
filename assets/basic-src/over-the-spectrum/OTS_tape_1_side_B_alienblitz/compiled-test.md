# Alien Blitz — MCODER III compatibility

**Compiles and loads; gameplay compatibility not verified.** Genuine compiler `0 OK`, ROM SAVE and independent fresh ROM LOAD succeeded on the unchanged publisher TZX. C/M/X real-key tests changed a few screen bytes, but captured images were fragmented and did not prove coherent ship movement and firing. The original source cassette contains the known misplaced `185 NEXT i` after line 330; the separately authorized correction to the *exported* BAS did not enter the compiler test. Original tape, compiled tape and original interpreted walkthrough remain preserved. No behaviour match claimed.
