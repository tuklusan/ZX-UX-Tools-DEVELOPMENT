**Incompatible as supplied.** Genuine MCODER III compilation of the unchanged publisher program stopped with `4 Out of memory, 5020:1`; the reported source statement is `5020 GO TO 4020` (not a dynamic DIM). One compiler block remained; no compiled output from the original source exists. The separate unmodified `frogshapes` initialization tape was first run on the SAME Spectrum, as the game requires. Exact internal cause of the memory exhaustion is unconfirmed. Original interpreted game walkthrough and frogshapes remain preserved.
